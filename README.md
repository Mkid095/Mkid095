## Engineering Philosophy

<div style="display:grid; grid-template-columns:1fr 1fr; gap:12px;">

<div style="background:#f9f9f9; border-radius:10px; padding:16px; border-left:4px solid #22c55e;">
<strong>Architecture before implementation.</strong>
<p style="margin:6px 0 0; font-size:13px; color:#555;">Understand the system before building individual features.</p>
</div>

<div style="background:#f9f9f9; border-radius:10px; padding:16px; border-left:4px solid #22c55e;">
<strong>Automation over repetition.</strong>
<p style="margin:6px 0 0; font-size:13px; color:#555;">If a process happens repeatedly, it should become infrastructure.</p>
</div>

<div style="background:#f9f9f9; border-radius:10px; padding:16px; border-left:4px solid #22c55e;">
<strong>Validate before proceeding.</strong>
<p style="margin:6px 0 0; font-size:13px; color:#555;">Each phase of a build is confirmed working before moving to the next.</p>
</div>

<div style="background:#f9f9f9; border-radius:10px; padding:16px; border-left:4px solid #22c55e;">
<strong>Observability over guesswork.</strong>
<p style="margin:6px 0 0; font-size:13px; color:#555;">Production systems should make failures visible and explain what happened.</p>
</div>

<div style="background:#f9f9f9; border-radius:10px; padding:16px; border-left:4px solid #22c55e;">
<strong>User experience over complexity.</strong>
<p style="margin:6px 0 0; font-size:13px; color:#555;">The system can be complicated internally. The user shouldn't have to care.</p>
</div>

</div>
